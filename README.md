# DiehardMusic — Releases

This repository hosts official releases of **DiehardMusic**, an AI-powered song request platform for DJs.

## Download

Head to [Releases](https://github.com/diehardmusic/diehardmusic-releases/releases) and download the latest `.dmg` file.

| Version | Platform | File |
|---------|----------|------|
| v1.0.2 | macOS (Apple Silicon) | `DiehardMusic-1.0.2-arm64.dmg` |

## Install

1. Open the `.dmg` file
2. Drag **DiehardMusic** into your Applications folder
3. Launch it — if macOS shows a security prompt, click **Open Anyway** in System Settings → Privacy & Security

**Requirements:** macOS 12 or later · Apple Silicon (M1/M2/M3)

## What is DiehardMusic?

DiehardMusic is a DJ tool that lets guests submit song requests by text or QR code. The built-in AI filters requests by energy, BPM, and vibe — so your queue stays curated and your set stays tight.
